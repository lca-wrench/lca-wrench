# Bundled flow mapping

`ecoinvent-3.11-biosphere-EF-3.1-biosphere.json.gz` is one of two data files distributed with LCA Wrench; the other
is the sector matching for EXIOBASE in `../sectors`.

- Name: ecoinvent-3.11-biosphere-EF-3.1-biosphere
- Version: 1.0.0
- Authors: Chris Mutel and the UNEP Economy Division GLAD mapping task force
- Distributed through [randonneur_data](https://github.com/brightway-lca/randonneur_data)
- Licence: CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/)
- Changes: none, the file is included unchanged.

It maps ecoinvent elementary flows to the EF 3.1 reference list and is used by LCA Wrench to apply methods across the two
lists (see `docs/flow-mapping.md`). Suggested attribution: Mutel, C. and the UNEP Economy Division GLAD mapping task
force: ecoinvent-3.11-biosphere-EF-3.1-biosphere, version 1.0.0, randonneur_data, CC BY 4.0.
